# 🐍 Python Reverse Shell – Eğitim Amaçlı Proje

Bu repo, **tamamen eğitim ve siber güvenlik farkındalığı amacıyla** hazırlanmış Python Reverse Shell örneğini içermektedir.  
Video anlatımında, bir reverse shell yapısının nasıl çalıştığını, saldırı senaryolarında nasıl kötüye kullanılabildiğini ve savunma tarafında bunlara karşı nasıl önlem alınabileceğini adım adım işledim.

❗ **Bu proje yalnızca eğitim, test ve laboratuvar ortamlarında kullanım içindir.**
